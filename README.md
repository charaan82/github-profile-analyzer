# GitHub Profile Analyzer

A web application built using Python and Streamlit that analyzes GitHub profiles and repositories.

## Features

- GitHub profile analysis
- Followers and following
- Public repositories
- Repository stars and forks
- Programming language information
- README analysis
- AI profile summary
- Downloadable report
- Simple Streamlit interface

## Technologies Used

- Python
- Streamlit
- GitHub REST API
- OpenAI API

## How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
Run the application:
streamlit run app.py
